### 🚀 Featured Project: [GPT-Graph-Analyzer](https://github.com/sabaath7766/GPT-Graph-Analyzer)
*Automating the analysis of complex data structures (subgraphs) using multi-stage LLM inference.*
- **The Problem:** Manual expert workflows for analyzing subgraphs are slow and error-prone.
- **The Solution:** A specialized pipeline that replaces manual analysis with a validation framework where a primary LLM cross-references multiple outputs to ensure technical consensus.
- **Impact:** Developed as part of my Master’s Thesis to enhance accuracy in complex data analytics.

### 🎓 Postgraduate Research: Multi-Agentic RAG for Archival Data
I am currently developing a specialized LLM ecosystem designed to navigate and retrieve information from dense historical archives.

*   **Continued Pre-training (CPT):** Training models on the **Perun HPC cluster** to adapt them to the nuances of archival language.
*   **Agentic RAG Architecture:** Built with **LangFlow** and **Vector Databases** for sophisticated data retrieval.
*   **Multi-Agent Orchestration Layer:**
    *   🔍 **Query Restructuring Agent:** Optimizes user input for precise lookups.
    *   🛡️ **Retrieval & Filtering Agent:** Ensures context relevance and data integrity.
    *   ✍️ **Summary Agent:** Synthesizes complex historical data into actionable insights.
